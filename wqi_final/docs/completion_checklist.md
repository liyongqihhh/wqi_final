## 当前结论

按任务书的软件实现范围估计，当前代码完成度约为 **90%**；按“代码、完整重复实验、
定量图表、论文结论和答辩证据全部齐备”的最终交付范围估计，完成度约为
**75% 至 80%**。主要软件闭环已经形成，剩余工作以正式实验和论文数据为主，而不是
继续增加大量新功能。

## 必须完成的收尾顺序

1. 全工作空间重新编译和测试，修复所有错误后冻结源代码版本。
2. 无界面运行 `3 模式 x 4 密度 x 3 种子 = 36` 次主实验矩阵。
3. 单独运行多目标、空载/有载、正常/低电量拒绝、停靠充电四类消融实验。
4. 检查每次记录中的 `collision_free`、UGV/UAV 最小动态净间距和碰撞事件数；
   不能只引用 Action 返回值。
5. 将 `runs.json`、`runs.csv`、`summary.md` 和 PNG 图复制到论文实验材料目录，
   计算均值、样本标准差并逐项解释失败原因。
6. 在论文中明确两个边界：UAV 使用 Gazebo ground truth 定位；起降时 UGV
   停在固定会合点，不支持车辆运动中的动态着陆。
7. 完成论文后再建立最终 Git 提交和版本标签，保证报告中的提交号与实验代码一致。

## 论文最低数据表

- 三种配送模式的任务时间、路径长度、总能耗和单目标能耗。
- 四种障碍密度的任务成功率、真实避障成功率、最小净间距、碰撞次数和恢复次数。
- UAV 不同载荷下的预测能耗、积分能耗和任务结束 SOC。
- UGV 空载/有载时的驱动能耗，以及独立充电电池向 UAV 输送的能量。
- 正常电量任务、UAV 电量不足、UGV 驱动电量不足和充电预算不足的准入结果。

## 可选增强

只有指导教师明确要求车辆运动中起降时，才建议增加移动平台视觉跟踪和动态着陆。
该功能会显著增加控制风险，不应在正式实验前替换已经稳定的固定会合点闭环。在线
三维 SLAM、真实无线链路和 PX4 硬件在环同样属于可选后续研究，不是当前仿真平台
完成定量毕业设计验收的前置条件。
