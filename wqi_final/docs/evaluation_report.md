# 当前开发基线验证与实验记录

## 报告范围

本报告记录 `wqi_final` 当前源代码能够复现的构建、自动测试、模型检查、单次运行
和自动指标采集证据。它不是最终论文的完整统计结果。尚未执行的正式实验矩阵、组间
均值和标准差均明确标为待采集，不使用推测值代替实测值。

历史验证始于 2026-07-20 至 2026-07-26，后续回归按日期追加。环境为 Ubuntu
22.04、ROS 2 Humble、Gazebo Classic 和 VirtualBox。系统仅面向电脑端仿真，
当前仅使用 PX4 SITL 后端；不包含开发板或真实电池遥测。旧版本的 SJTU、控制界面
与地图生成器验证保留为历史记录，不代表这些源码仍在当前交付范围。

### 2026-07-26 阶段六机器人侧动态避障回归

## 结论与剩余风险

已有验证覆盖编译、接口生成、单元测试、lint、模型解析、地图资源、物理动态
障碍和自动报告要求。毕业设计的软件主体已经形成，但应在提交论文前建立最终 Git
标签并在该标签上执行 `evaluation_method.md` 定义的完整矩阵。最终论文
证据仍缺少统一采集的多轮整程数据、成功率/标准差图表、能耗预测误差标定以及加载
与空载对照。UAV 仍使用 Gazebo ground truth 定位；它具有航路边重规划和局部三维
绕行，但不构建在线三维全局占据地图。PX4 后端内部融合模拟飞控传感器，校园 map
对齐仍使用 Gazebo ground truth，不能表述为已经完成独立 GPS/IMU 或 SLAM 定位。
UGV 在道路间作为移动基地运行，但起飞和降落期间会停在固定会合点，当前不支持车辆
行驶中的动态追踪着陆。这些边界必须在论文中如实说明。
